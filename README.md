# לוח שנה עברי משפחתי (תשפ״ז)

לוח שנה עברי מלא לשנת תשפ״ז (שנה מעוברת, 13 חודשים), הכולל:
- תצוגה חודשית מעוצבת ומותאמת אישית לכל חודש
- ימי הולדת של בני המשפחה עם תמונות פנים ממורכזות ומותאמות
- פרשות שבוע, חגים, מועדים וספירת העומר
- אפשרות הדפסת A4 לחודש בודד או לכל 13 החודשים ל-PDF
- הוספה ועריכה של אירועים אישיים

## הרצה מקומית

```bash
npm install
npm run dev
```

ברירת המחדל מפעילה שרת פיתוח בכתובת `http://localhost:8443`.

## בנייה (Production)

```bash
npm run build
```
